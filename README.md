# Dummy Fight

브라우저에서 바로 실행되는 자동 전투 시뮬레이션입니다.

## 구성

- Red Dummy: short blade
- Blue Dummy: spear
- 설정한 출혈량에 먼저 도달한 더미가 패배
- 머리 / 몸통 / 양팔 / 양다리의 독립 내구도
- 팔·다리 파츠 분리
- 오른팔이 분리되면 들고 있던 무기를 떨어뜨리고 사용할 수 없음
- 무기 사용이 불가능하면 남은 팔 공격 → 남은 다리 공격 순으로 전환
- 다리 손상에 따라 이동 속도 감소, 양다리 상실 시 매우 느린 이동
- 전투 로그, 속도, 출혈 한계, 파츠 분리 확률, AI 공격성 조절
- 외부 라이브러리나 에셋 없이 HTML/CSS/Canvas JavaScript만 사용

## 실행

`index.html`을 브라우저에서 열면 됩니다. 정적 파일만 사용하므로 별도의 빌드 과정은 없습니다.

GitHub Pages를 사용할 경우 저장소의 **Settings → Pages**에서 main 브랜치의 루트 디렉터리를 배포 소스로 선택하면 됩니다.

## 표현 방식

더미 파츠가 분리되는 물리 효과는 있지만 고어 표현은 사용하지 않습니다. 출혈은 숫자와 게이지로만 표시합니다.
